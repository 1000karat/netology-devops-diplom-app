#### Netology DevOps Diplom App

version: 1.0.6

Проект - это ограниченное во времени предприятие (мероприятие), направленное на создание
уникальных продуктов и услуг или получение принципиально новых результатов.
Проект может существовать в двух формах:
1. Как составная часть программы, представляющая собой форму конкретизации и
содержательного наполнения приоритетных направлений развития социокультурной жизни
территории.
2. Как самостоятельный вариант решения локальной проблемы, адресованный конкретной
аудитории.
